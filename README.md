## Команды:

Убедитесь, что установлены: Docker & Docker Compose (либо Docker Desktop с встроенным compose)

```bash
# Собрать образы и запустить контейнеры в фоновом режиме
npm run docker:api

# Запустить контейнеры в фоновом режиме (без пересборки)
npm run docker:up

# Остановить контейнеры
npm run docker:down
```
